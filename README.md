# Halium

Halium — настольное приложение на Rust для Windows (`eframe` / `egui`), предназначенное для автоматической сборки скриптов Python (`.py`) в автономные исполняемые файлы (`.exe`).

## Возможности

- **Drag & Drop интерфейс:** перетащите `.py` файл в окно приложения для мгновенного запуска компиляции.
- **Smart Dependency Resolver:** автоматический разбор импортов через AST с поддержкой локальных модулей скрипта.
- **Изолированное окружение:** чистая сборка во временной директории (`%TEMP%`) без затягивания лишних системных пакетов.
- **Автоматический выбор режима:** распознавание GUI библиотек (`tkinter`, `customtkinter`, `PyQt`, `PySide`, `pygame` и др.) и установка флага `--noconsole`.
- **Сохранение метаданных:** передача `--copy-metadata` для предотвращения `PackageNotFoundError`.

## Требования

- Windows 10/11 x64
- Установленный Python 3.8+ в системе

## Сборка из исходников

```powershell
cargo build --release
```

Исполняемый файл будет доступен в `target/release/halium.exe`.
